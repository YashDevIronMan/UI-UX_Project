# CampusConnect — UI/UX Project

CampusConnect is a UI/UX project focused on helping students find
faculty and admin staff, check their availability and schedule,
and decide when to visit.

## Project Overview

This project was developed as part of my HCI / UI/UX coursework.

The project includes:
- User Research
- Empathy Mapping
- User Journey
- Information Architecture
- Card Sorting
- Tree Testing
- Feature Prioritization
- Wireframing
- Interactive Prototyping
- Usability Testing
- Peer Benchmarking

## Problem

Students often don't know whether the faculty or admin person they
need to meet is available. This can lead to unnecessary visits,
waiting and repeated trips.

## Solution

CampusConnect follows a simple flow:

**Find → Check → Decide**

Students can find a faculty or admin person, check their availability,
schedule and office timings, and decide when to visit.
